# Contributing to Smida-Wiem

## How to Create a Milestone

Milestones in GitHub help you track progress toward a goal by grouping related issues and pull requests together.

### Steps to Create a Milestone

1. **Navigate to the repository** on GitHub at [Smida-Wiem/Smida-Wiem](https://github.com/Smida-Wiem/Smida-Wiem).

2. **Go to the Issues tab** at the top of the repository page.

3. **Click "Milestones"** next to the search bar (or navigate directly to `https://github.com/Smida-Wiem/Smida-Wiem/milestones`).

4. **Click "New milestone"** (green button in the top-right corner).

5. **Fill in the milestone details:**
   - **Title** – Give your milestone a clear, descriptive name (e.g., `v1.0`, `Sprint 1`, `Q2 Goals`).
   - **Due date** *(optional)* – Set a target completion date.
   - **Description** *(optional)* – Add context about what this milestone represents.

6. **Click "Create milestone"** to save it.

### Assigning Issues and Pull Requests to a Milestone

- When creating or editing an issue/pull request, look for the **Milestone** section in the right sidebar.
- Click on it and select the milestone you want to assign.

### Tracking Milestone Progress

- Visit the **Milestones** page to see an overview of open and closed items for each milestone.
- The progress bar shows the percentage of completed issues and pull requests.

---

For more information, see the [official GitHub documentation on milestones](https://docs.github.com/en/issues/using-labels-and-milestones-to-track-work/about-milestones).
